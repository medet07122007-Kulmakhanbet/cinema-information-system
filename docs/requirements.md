
# Кинотеатр ақпараттық жүйесінің талаптары

## Функционалдық талаптар
1. Клиент фильмдер тізімін көре алады.
2. Клиент сеанс таңдай алады.
3. Клиент билет брондай алады.
4. Кассир билет сата алады.
5. Әкімші фильмдерді басқара алады.

## Функционалдық емес талаптар
1. Жүйе жылдам жұмыс істеуі керек.
2. Пайдаланушы деректері қорғалуы тиіс.
3. Интерфейс қолдануға ыңғайлы болуы керек.
