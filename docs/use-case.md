
# Кинотеатр ақпараттық жүйесінің Use Case

## Акторлар
1. Клиент
2. Кассир
3. Әкімші

## Клиенттің әрекеттері
- Фильмдер тізімін қарау
- Сеансты таңдау
- Бос орындарды қарау
- Билет брондау

## Кассирдің әрекеттері
- Билет сату
- Брондауды тексеру

## Әкімшінің әрекеттері
- Жаңа фильм қосу
- Фильм туралы ақпаратты өзгерту
- Сеанстарды басқару

## Қорытынды
Бұл ақпараттық жүйе кинотеатр жұмысын автоматтандырады және билеттерді брондау мен сату процесін жеңілдетеді.
